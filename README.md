# BlenderRenderMultiple

Plugin en Python para renderizar varios archivos .blend a la vez y en segundo plano haciendo más optimo el render.

**Installar PyInstaller:**

pip install pyinstaller

**Crear .exe:**

pyinstaller --onefile --windowed blender_batch_gui_pro.py
